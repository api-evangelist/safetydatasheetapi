# Safety Data Sheet (SDS/MSDS) Extraction API

A REST API by SafetyDataSheetAPI (a product of DscvryAI) that converts Safety Data Sheet PDFs into normalized 16-section structured records (product identity, GHS/H&P statements, composition, exposure controls/PPE, tox/eco data, disposal, transport, regulatory, revision metadata) output as JSON, XML, and CSV with confidence scores and warnings. Supports OCR for scanned PDFs, multilingual input, custom schema mapping, and bulk/webhook async flows.
